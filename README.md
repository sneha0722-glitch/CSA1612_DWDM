# DWDM Lab – Interactive Experiments

This repository contains browser-based demonstrations for Data Warehousing and Data Mining lab work.

## Open the 13-experiment page
Open [experiments.html](experiments.html) in Chrome or Edge. It includes interactive/sample demonstrations and short instructions for all 13 experiment topics.

## Apriori and FP-Tree tool
Open [index.html](index.html) for the interactive Apriori frequent-itemset and FP-Tree demonstration.

## Important data note
Some original assignment datasets and the decision-tree diagram for Experiment 9 were not available in the accessible question text. Where data was missing, the experiments are clearly labelled as sample demonstrations. Replace sample values with the exact values from the question paper before submitting numerical results.
